# 💖 HAPPY ANNIVERSARY — CINEMATIC LOVE EXPERIENCE 2026

An ultra-luxury, cinematic, interactive anniversary web experience designed like a Hollywood romantic movie intro combined with a Gen-Z 2026 aesthetic.

Built with **React 18**, **Three.js**, **Framer Motion**, **Tailwind CSS**, and **HTML5 Canvas VFX Engines**.

---

## ✨ Features & Cinematic Scenes

### 1. 🎬 Opening Scene — Cinematic Intro
- Pure cinematic dark background (`#030106`) with atmospheric colored fog and drifting stardust.
- Glowing SVG Heartbeat ECG line pulsing with realistic "lub-dub" heartbeat audio.
- Particle heart formation with camera zoom effect.
- Staggered typography: *"Something beautiful is about to begin..."* & *"FOR SOMEONE SPECIAL ❤️"*.
- Interactive button **"ENTER OUR WORLD ✨"** with soft screen flash, sound burst, and explosive particle transition.

### 2. 🌌 Hero Section — The Heart of the Experience
- Metallic gold, rose gold, and neon pink animated gradient typography with letter-by-letter entrance.

- Real-time Three.js 3D parametric heart constructed from over 4,500 glowing points.

- Ambient point lights in crimson, electric pink, and golden champagne.

### 5. 📸 Cinematic Photo Gallery & Time Capsule
- 3D floating glassmorphic picture cards with hover zoom and light reflections.
- Complete interactive local photo management:
  - **Drag & Drop** your own photos directly into the gallery.
  - **Live Preview** with high-resolution rendering.
  - **Image Rotation** button (90° increments).
  - **Replace or Delete** photo slots.
  - Fullscreen cinematic lightbox modal.

### 6. ✨ "I LOVE YOU" — Heart Formation VFX
- Fullscreen custom particle simulation engine.
- Thousands of glowing neon particles calculate target coordinates in 3D along a heart curve.

- Card button: **"HOW MUCH DO I LOVE YOU? ❤️"**.

### 9. 🎆 Final Cinematic Scene & Replay Loop
- Giant pulsating heart with glowing fireworks and heart-shaped burst trajectories.

  - *"IN EVERY UNIVERSE..."*

### 10. 🎵 Web Audio API Sound Engine & Music Player
- **Zero Network Errors**: Built-in Web Audio API synthesizer generates rich ambient piano chords in F major / D minor, realistic heartbeat thumps, whooshes, and chimes.

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS 3
- **3D Graphics**: Three.js
- **Animations**: Framer Motion & GSAP
- **VFX & Confetti**: Custom HTML5 Canvas Engines & Canvas-Confetti
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizer

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌐 Vercel Deployment

Deploying this project to Vercel is completely free and requires zero paid APIs:

### Option A: Via Vercel Dashboard (Recommended)
1. Go to [https://vercel.com](https://vercel.com) and log in.
2. Click **"Add New Project"** and select **"Import Git Repository"**.
3. Choose your GitHub repository (`cinematic-happy-anniversary-2026`).
4. Framework Preset: **Vite** (auto-detected).
5. Root Directory: `anniversary 1` (or `./` if repository root).
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Click **"Deploy"**. Your live production URL will be ready in under 60 seconds!

### Option B: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
Follow the interactive prompts to deploy to preview, and run:
```bash
vercel --prod
```
to deploy directly to production.
